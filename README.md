# 주문·업무 찾기 실제 구현

확정한 목업을 React 앱에 반영했다. 기본 화면은 주문·업무 찾기이며 운영 대시보드 본체는 유지했다. 흑백, 진한 회색 버튼, 작은 글자와 밀도 높은 목록을 적용했다.

## 실행

상위 폴더의 `미리보기-시작.cmd`를 실행하고 `http://127.0.0.1:5178/`을 연다. Node.js가 필요하며 최초 의존성 설치에 인터넷 연결을 사용한다. 서버 창에서 Ctrl+C를 누르면 종료된다.

현재 검증용 실행 주소는 `http://127.0.0.1:5175/`이다. 두 주소는 브라우저 저장소가 구분되므로 실제 사용하는 주소를 일정하게 유지한다.

직접 실행할 때:

```powershell
cd code
npm ci
$env:ORDER_PREVIEW_DATA = (Resolve-Path ../preview/order-full-preview.json).Path
npm run dev -- --port 5178 --strictPort
```

실제 XLS를 매입 자료 갱신 화면에서 읽어 저장할 수도 있다. 원본 자료는 개발 전용 경로에서 읽으며 배포 번들에 포함되지 않는다. Firebase 환경 변수가 없는 현재 실행은 IndexedDB에 이 기기 자료를 저장한다.

## 주요 동작

- 상품명 일부·약품코드·연결 바코드로 검색한다. 새 검색은 전체 용도로 돌아간다. 거래처 이름 일부도 후보로 나오며 카드 전체를 누르면 그 거래처 품목으로 들어간다.
- 상품을 펼치면 거래처별 최신 매입을 날짜순으로 표시한다. 처음 5곳, 나머지는 다른 거래처 보기로 펼친다. 단가와 날짜는 두 줄이다. 단위 미확인 가격은 원본 단가를 그대로 쓰고 `/ 단위`로 표시한다. 할인·할증은 적용하지 않는다.
- 전문약은 기본 단위 입고 개념을 쓰며, 일반약은 포장별 상품을 유지한다. 단위는 직원이 확인한 설정만 사용한다.
- 주문은 짧은 검색명을 복사하고 새 탭을 연다. 주소가 없으면 주소·주문 방법을 등록할 수 있다. 전화/문자/카카오톡·메모와 상품별 예외를 지원한다. 동일 즐겨찾기 사이트를 참조하면 주소 수정이 함께 반영된다.
- 관리에서 즐겨찾기 편집·가져오기, 자료 갱신, 새 상품, 직전 자료 복원, 모바일 글자 크기를 조정한다. 하위 화면 닫기는 상위 편집/관리로 돌아간다.
- 폴더는 편집에서 끌어 순서나 상위를 바꾼다. 가운데는 하위 이동, 위·아래 가장자리는 순서 변경이다. 자기 자신/자손 안으로 이동할 수 없다. 폴더 삭제는 내용물을 상위로 보존한다. 사이트는 폴더 선택과 끌기 이동을 지원한다. 고정 즐겨찾기 수 제한은 없다.
- 북마크 파일에서 폴더/사이트를 골라 가져온다. 검색 전에 선택한 항목을 유지하고 동일 이름·주소는 제외한다. 삭제한 사이트는 30일 이내 복원할 수 있다.
- 휴대폰에서는 검색창 고정, 바코드 아이콘, 오른쪽의 작은 주문 버튼, 원형 맨 위 버튼을 사용한다. 글자 크기는 기기별 저장한다.

## 직원 확인표

| 확인 | 기대 결과 |
|---|---|
| `백제` 입력 후 거래처 카드 누르기 | 원본 거래처명 표시, 연결 품목 즉시 진입 |
| `타이레놀` 입력 후 상품 펼치기 | 상품 구별 가능, 최근 날짜순 비교표와 매입 날짜 |
| 거래처 범위에서 상품명 입력 후 새 검색 | 범위 안 검색, 범위 해제 시 전체 검색 |
| 최근/가나다/매입 기록 순 전환 | 날짜/이름/기간 내 매입 기록 건수 순으로 변경 |
| 주소 없이 거래처 등록, 주소 등록 후 주문 | 빈 주소 등록 가능, 실제 주소로 새 탭 열기·짧은 검색명 복사 |
| 동일 사이트 여러 거래처와 상품별 예외 | 공통 주소 유지, 예외는 해당 상품만 적용 |
| 미등록 바코드 → 이름 검색 → 연결 → 재스캔 | 연결한 상품 조회, 기존 다른 바코드 유지 |
| 폴더 이동·하위 추가·삭제 | 내용 유지, 자손 안으로 이동 차단 |
| 가져오기 선택 후 검색어 변경 | 숨겨진 선택 유지, 가져온 수/제외한 중복 수 안내 |
| 관리 하위 화면 닫기 | 관리 또는 즐겨찾기 편집으로 복귀 |
| 새로고침 후 조회 | 저장한 자료·설정 유지 |
| 휴대폰 긴 이름·목록 스크롤 | 가격과 겹치지 않음, 검색 고정, 맨 위 이동 |

## 검증과 남은 환경 연결

실제 매입 33,905행과 조제·판매 목록을 포함한 21파일 92개 자동 검증이 통과했다. TypeScript 및 배포 빌드가 통과했다. 브라우저에서 실제 단가/날짜, 거래처 일부 검색, 1,006품목 조회, 390px 화면, 관리 하위 복귀와 새로고침 후 저장 유지를 확인했다. `전체검증-실행.cmd`로 다시 검증한다.

외부 공용 사용에는 배포 주소와 Firebase 설정이 필요하다. 기존 저장 코드에는 공용 변경/버전 충돌 처리가 있지만 현재 환경에서 다중 PC 동기화를 검증하지 않았다. 카메라 구현은 HTTPS에서 작동하며 실제 휴대폰과 USB 스캐너로 한 번 확인해야 한다. 현재 localhost 주소는 외부 휴대폰 접속 주소가 아니다. 빌드는 성공했지만 큰 JS 번들 경고가 남아 있다.
