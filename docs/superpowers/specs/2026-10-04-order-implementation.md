# 주문·업무 찾기 확정 화면 구현
현재 order-real-data-validation.html에서 확인한 상품·거래처 검색과 모바일 배치를 실제 React 화면으로 옮긴다. 운영 대시보드는 변경하지 않는다. 로그인 없는 사용은 기존 Firebase 연결 구조를 재사용하며 배포/외부 서비스 생성은 별도 작업이다.
- 상품명 일부·바코드·약품코드 검색, 거래처 일부 이름으로 품목 진입. 새 검색은 전체 용도, 새 거래처는 최근 매입순.
- 상품 왼쪽 이름/회사·코드, 오른쪽 단가/단위와 매입 날짜·거래처 두 줄. 미확인 단위는 ‘단위’. 후보 다수 접기, 클릭 비교표 펼치기, 최근순 5곳+더 보기. 모든 양의 가격 상승 안내, 5% 이상 강한 안내. 할인/할증 보정 없음.
- 전문약은 기본 단위 입고 개념, 일반약 포장별 상품 유지. 확인하지 않은 단위 추정/환산 없음. 바코드는 상품별 복수 수동 연결, 중복 연결 이동 확인, 이름 검색만 시작하면 연결 안내 없음.
- 새 탭 주문+짧은 상품명 복사. 공통 사이트 여러 거래처, 주소 비워 등록, 전화/문자/카카오톡 메모와 상품별 예외. 공통 주소는 동일 사이트 참조.
- 즐겨찾기 제한 없음. 중첩 폴더 추가/수정/삭제, 삭제시 내용 상위로 보존. 폴더·사이트 끌기 이동/순서, 휴대폰 위치 버튼. 편집 화면과 하위 화면 복귀.
- 가져오기 폴더/사이트 검색과 하위 체크, 초기 미선택, 검색전 선택 보존, 같은 이름·주소 제외, ‘가져온 즐겨찾기’ 묶음과 결과 건수.
- 모바일 sticky 검색, 바코드 아이콘, 기기별 글자 크기, 원형 맨 위 버튼. 흑백·얇은 회색선·진한 회색 버튼·확정 글자 크기.
- 원본 XLS 정상 양수 입고/기준일까지 사용, 최근1년 빈도 대체, 이전 기간 각 거래처 최근3건 보존, 공유 버전 충돌 보호. 실제 카메라 및 외부 PC 공유는 환경에서 확인한 범위만 보고한다.
